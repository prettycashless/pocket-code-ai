# Pocket Code Ai

Make me a mobile only coding ai agent. Name it "Neola", and make the interface terminal like close to the one in the picture. Generate a logo for it. Make the interface dark. Make it so the AI it uses is the personal tokens of the person with the app. It can set the APi Keys of Mistral, Muse Spark, Groq, and OpenRouter. He can change the models via command. The person can make multiple sessions. The data for the conversations, the AI, projects, history, and all that are saved locally on the phone files. Github integration will be made later. For now focus on the frontend.
